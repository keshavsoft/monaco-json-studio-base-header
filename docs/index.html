The Story

Instead of hardcoding HTML inside JS, every header variant (title.hbs, file-picker.hbs, select.hbs, actions.hbs) is a clean Handlebars template in assets/v1/templates/.

CLI & API

npx monaco-json-studio-base-header file-picker
npx monaco-json-studio-base-header select --html
