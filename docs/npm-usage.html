Programmatic (npm) Usage

Install and import monaco-json-studio-base-header inside Node.js ESM projects.

Install & Import

npm install monaco-json-studio-base-header
import { renderHeader, generateHeaderPreview, HEADER_TYPES } from 'monaco-json-studio-base-header';

const html = renderHeader({ type: 'file-picker', label: 'JSON Studio' });
generateHeaderPreview({ type: 'select' });

Exports renderHeader(), generateHeaderPreview(), HEADER_TYPES, and assetsDir (pointing to css/, templates/, and js/bindings.json + actions.js).
