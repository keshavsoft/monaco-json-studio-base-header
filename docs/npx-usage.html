CLI (npx) Usage

Run monaco-json-studio-base-header directly from the terminal without cloning.

Commands

npx monaco-json-studio-base-header file-picker
npx monaco-json-studio-base-header select
npx monaco-json-studio-base-header actions --html

Generates a standalone preview folder (./header-<type>, auto-incrementing -1, -2 if it exists) or prints the rendered .hbs fragment when --html is passed.
